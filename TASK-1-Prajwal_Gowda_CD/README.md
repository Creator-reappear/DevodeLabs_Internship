# 📜 Quest Log - To-Do List Application

A dynamic, terminal-based To-Do list manager built with Python. Developed as part of the **DecodeLabs Internship** curriculum.

## 🚀 Features
* **Insert Quests:** Add tasks dynamically to your custom adventure log.
* **Auto-Numbering:** Leverages `enumerate()` for clean, human-readable indexing.
* **Delete Functionality:** Safely remove completed items using the `.pop()` method.
* **User Safety Net:** Built-in validation to check for out-of-bounds input index values.

## 🛠️ How to Run
Ensure you have Python installed, then run the script via your terminal:
```bash
python your_filename.py
```
